# My Projects

Ask your agent to create a project here or register one that already exists elsewhere.

Each new project gets its own Git history, front page, and lab notebook. Existing projects stay where they are; a small reference folder helps the agent find and describe them. Your project folders and optional private `Workspace.md` overview are excluded from the public Science with Agents repository.

Say “Show my projects,” “What needs my attention?”, or “Add the project in this folder.” The agent follows [setup](../docs/setup.md#project-structure) and checks the actual project before writing. The folder alone does not start a manager or enable GitHub sync.
