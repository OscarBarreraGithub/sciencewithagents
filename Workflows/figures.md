# Reuse a plotting method

Start with the quantity to show, the scientific claim, and the input data or calculation. Inspect any existing figure recipe. A researcher may supply a group's public plotting scripts, styles, or paper source; preserve its authorship and reuse terms.

Read the chosen project's current installation instructions, inspect dependencies, and establish the smallest compatible environment. Existing examples include [SciencePlots](https://scienceplots.readthedocs.io/) and [mplhep](https://mplhep.readthedocs.io/). These are optional methods, not required dependencies or guarantees about journal acceptance.

Adapt the recipe to the actual inputs. Check units, labels, normalization, axis choices, uncertainty, and the intended comparison. Save the script, style/version, parameters, source data references, and output together with the scientific work. Record material presentation choices in the notebook.

Regenerate the figure from the saved inputs where feasible and inspect the actual image. The paper companion should contain enough to reproduce the plotted content and style, with external dependencies and unavailable data explicit. Keep private paths and embedded metadata out of shared exports.
