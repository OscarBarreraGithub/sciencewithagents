# Literature search

Define the scientific question, scope, date range, and useful stopping point. Read existing references and previous searches before repeating them. By default suggest an available deep-research service or equivalent; use an imported group's method when selected.

Inspect what the current agent can launch and retrieve. Consult the selected service's current documentation and establish missing access using the user's account. If it cannot be launched here, guide the researcher to start it and import the resulting report. Record that route and its limits.

Search within the agreed scope. Save bibliographic identifiers, source links, relevant passages or locations, competing conclusions, and uncertainty. Check that each important citation exists and supports the claim attributed to it. Prefer original papers for scientific premises and distinguish their findings from an agent's interpretation.

Integrate the findings into the notebook and reference files, with sources attached to the assumptions or results they support. Note coverage limits, unavailable papers, and unresolved disagreements. Preserve only the permitted source content; personal search prompts remain private. A report is not a verified premise merely because it contains citations.
