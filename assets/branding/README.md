# Alien artwork

`alien-drawing.png` is the owner's original `aliens.png` drawing used for Heldalive.
Keep its hand-drawn strokes; do not replace it with the pixel-style recreation.
The original white ink and transparent background are retained here.

Source SHA-256: `672b99edc8e12b8c3ab018f6aa381a650f6fca395c4a738cee06dc01a09c92cb`.

Run `node scripts/export-web-icons.mjs` to regenerate the app and website SVGs,
phone icons, VS Code icon and (on macOS) the application icon. The SVGs embed this
image and tint its ink green for the light interface; the drawing is not redrawn.
Preview files stay under ignored `data/`.
