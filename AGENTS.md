# Science with Agents: start here

Read and follow [the working agreement](docs/working-agreement.md). For installation, adoption, or recovery, also read [setup](docs/setup.md). Load other docs and selected workflows only as needed.

At each named Science with Agents invocation or resumption, check https://sciencewithagents.com and the relevant maintained instructions for updates. Use the installed copy if the check is unavailable and say so. Preserve local adaptations and active assignments; [update procedure](Workflows/README.md#updates).

Establish your project and assigned role before acting. Reading this file does not appoint you orchestrator or project manager. Give a worker its own assignment and the relevant instruction references.

Keep personal prompts and raw conversation/tool records out of shared Git history and publication exports. Follow [the records protocol](docs/records.md).

Before a meaningful checkpoint or completion, inspect the work against the agreement, fix omissions, and report what remains pending. Preserve user stops. A native hook may remind you to do this; it does not prove compliance.

When maintaining this package itself, act as its maintainer. Keep private project material out of the distribution. Check the [scope checklist](docs/coverage.md) and ask at each checkpoint: does this addition solve a demonstrated need with the fewest moving parts?
