# Guide

Start by asking your agent to use Science with Agents. It reads the instructions and helps establish the parts you need. You can read these pages yourself, but you should not have to operate the files by hand.

| Topic | Read |
| --- | --- |
| New setup, existing projects, and the folder structure | [Setup](setup.md) |
| Managers, workers, the notebook, Git, and collaboration | [Working agreement](working-agreement.md) |
| Who did what, private tool records, and a paper supplement | [Records](records.md) |
| Browser, phone, IDE, native hooks, and troubleshooting | [Connections](connections.md) |
| Import, enable, update, or create a method | [Workflows](../Workflows/README.md) |
| The five-page explanation | [Paper](paper/science-with-agents.pdf) |
| What is included and what is still unverified | [Scope and checks](coverage.md) |

Ask “What can I do here?” for a short menu based on the current project's available tools. “What is active?” should list the project, assignment, manager, selected methods, running or pending work, and any missing connection. A copied workflow is available; it is active only when selected and running only when a job was actually started.

Routine work should feel like a conversation with a colleague: a short explanation of the next step, useful progress updates, and a clear account of the result. Ask the agent to explain more or proceed more quickly at any time.
